# Repository boundary

Status: accepted for local tooling construction.

SPIKE-CALIBRATOR owns its repository validators now. Its planned domain responsibility is measurement of declared spiking-classifier confidence, complete shift and placement curves, calibration reports and prior-policy deployment verdicts. It does not own a second evidence signing root, a neuron simulator, instrument metrology or physical parameter fitting.

Initial metadata is local governance data. The planned report identifier is separate from registered or qualified formats. Validation reports cover infrastructure only; no model-confidence runtime package or released API is asserted before it exists.

Future changes must add actual public evaluation, raw-population preservation, independent references, consumer wiring, strict checks, tests, documentation and applicable benchmark parity in the same complete change. Measurement and policy evaluation do not authorize v1 post-hoc correction.
